这是我的第一篇文章。

我想用一个简单的页面，记录正在学习的东西、做过的小项目，以及一些不想忘记的想法。之所以选择自己搭一个博客，而不是把内容散落在各种平台里，是因为我想有一个完全属于自己的地方：页面长什么样、文章怎么排、链接指向哪里，都由我自己决定。

## 我想记录什么？

- 学到的新概念，尤其是那些卡了很久才搞懂的部分
- 做项目时遇到的问题，以及最后是怎么绕出来的
- 读过的文章和书里值得记下来的句子
- 下一步想尝试的事情

## 为什么用这种方式

这个博客没有用任何前端框架，也没有数据库。文章就是普通的 Markdown 文件，放在 `_posts` 文件夹里；提交到 GitHub 之后，由 GitHub Actions 自动把它编译成 HTML 并发布到 GitHub Pages。

这样做的好处是：写作只需要打开一个文本文件，不用担心环境坏掉，也不用维护服务器。

## 接下来

先把写作变成习惯。技术细节可以慢慢打磨，能持续写下去才是最重要的。以后只需要复制这个文件，修改文件名、标题和正文，就能继续写下一篇。
